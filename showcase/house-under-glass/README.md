# The House Under Glass

The House Under Glass is planned as Moonroom's polished showcase game: a small parser-fiction mystery about a rain-lashed house, a tarnished key, and rooms that remember who has passed through them.

This directory is currently a scaffold with a minimal playable opening room. See [PLAN.md](PLAN.md) for the intended story shape, room list, puzzle chain, and engine features the showcase should exercise.

## Status

Minimal scaffold only. `examples/house` remains the current complete playable integration example.

## Intended Commands

```bash
cargo run -q -p mr-cli -- play showcase/house-under-glass
cargo run -q -p mr-cli -- test showcase/house-under-glass
```
